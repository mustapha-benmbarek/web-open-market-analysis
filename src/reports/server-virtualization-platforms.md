# Server Virtualization Platforms

The server virtualization market faces the most significant disruption in over a decade. Heads of I&O must reevaluate the vendor and technology options for current and future virtual workloads and respond accordingly.

## Market Definition

Gartner defines server virtualization platforms as a technology solution that decouples operating systems and workloads from the underlying physical infrastructure. This enables multiple isolated virtual environments to run concurrently across a cluster of hosts while providing centralized management, automation and resource orchestration.

Server virtualization platforms can be used by enterprises to optimize IT infrastructure and improve service levels within data centers and remote locations. Service providers often use a server virtualization platform as an embedded component of their infrastructure as a service (IaaS) offerings and/or for delivering a hosted server virtualization platform.
